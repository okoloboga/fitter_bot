# Инструкция по тестированию GPT Image моделей

## Описание

Скрипт `test_gpt_image_models.py` проверяет подключение к модели генерации изображений через CometAPI: GPT Image 1.5.

## Запуск теста

### Вариант 1: Через Docker (рекомендуется)

1. Убедитесь, что в `.env` файле есть `COMET_API_KEY` или `IMAGE_GEN_API_KEY`

2. Если контейнеры уже запущены:
```bash
docker compose exec bot python test_gpt_image_models.py
```

3. Если контейнеры не запущены:
```bash
docker compose run --rm bot python test_gpt_image_models.py
```

### Вариант 2: Локально (требует установки зависимостей)

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Установите переменную окружения с API ключом:
```bash
# Linux/Mac
export COMET_API_KEY='your-api-key-here'

# Windows PowerShell
$env:COMET_API_KEY='your-api-key-here'

# Windows CMD
set COMET_API_KEY=your-api-key-here
```

3. Запустите тест:
```bash
python test_gpt_image_models.py
```

## Что тестирует скрипт

Скрипт проверяет следующие модели:

### Рабочие модели (для проверки):
- `gemini-2.5-flash-image` - Быстрая модель
- `gemini-3-pro-image` - Качественная модель

### GPT Image модели (разные варианты названий):
- `gpt-4-image-1`
- `gpt-4-image-1.5`
- `gpt-image-1.5`
- `openai-image-1`
- `openai-image-1.5`

## Что показывает тест

Для каждой модели скрипт:

1. **Пробует разные endpoint'ы:**
   - `/v1beta/models/{model}:generateContent` (стандартный Gemini endpoint)
   - `/v1/images/generations` (возможный OpenAI-совместимый endpoint)
   - `/v1/chat/completions` (chat completions endpoint)

2. **Показывает результаты:**
   - ✅ Успешное подключение
   - ❌ Ошибки (404, 401, 400, и т.д.)
   - ❌ Исключения (RemoteProtocolError, ConnectError, TimeoutException)

3. **Выводит итоговый отчет:**
   - Список рабочих моделей
   - Список не работающих моделей
   - Рекомендации по использованию

## Интерпретация результатов

### ✅ Модель работает
- Модель доступна и принимает запросы
- Можно использовать в боте

### ❌ Модель не работает

**404 Not Found:**
- Endpoint не найден
- Возможно, неправильное название модели
- Или модель недоступна в вашем тарифе

**401 Unauthorized:**
- Проблема с API ключом
- Проверьте правильность ключа

**400 Bad Request:**
- Неверный формат запроса
- Возможно, для этой модели нужен другой формат body

**RemoteProtocolError:**
- Сервер разорвал соединение без ответа
- Возможно, модель не поддерживает такой формат запроса
- Или endpoint неверный

## Следующие шаги

1. **Если модель работает:**
   - Обновите маппинг в `bot/handlers/tryon.py` с правильным названием
   - Обновите документацию

2. **Если модель не работает:**
   - Проверьте документацию CometAPI: https://apidoc.cometapi.com/image-edits
   - Уточните точное название модели
   - Проверьте, доступна ли модель в вашем тарифе
   - Возможно, нужен другой формат запроса

3. **Если все GPT Image модели не работают:**
   - Возможно, они недоступны в вашем тарифе CometAPI
   - Или требуют другого формата запроса (не Gemini-совместимый)
   - Проверьте документацию на предмет специального API для GPT Image моделей

## Устранение проблем

### Ошибка: "Не найден API ключ"
```bash
# Проверьте, что переменная установлена
echo $COMET_API_KEY  # Linux/Mac
echo $env:COMET_API_KEY  # Windows PowerShell
```

### Ошибка импорта модулей
```bash
# Убедитесь, что вы в корневой директории проекта
cd /path/to/fitter_bot
python test_gpt_image_models.py
```

### Ошибка подключения к API
- Проверьте интернет-соединение
- Проверьте, что `base_url` правильный
- Проверьте файрвол/прокси настройки
