# Подключение GPT Image -1 и 1.5 как дополнительные модели

## ЦЕЛЬ ЗАДАЧИ
Добавить поддержку моделей GPT Image -1 и GPT Image 1.5 в качестве дополнительных опций для генерации примерки одежды. Пользователи смогут выбирать между 4 моделями: Быстрая, Качественная, GPT Image -1, GPT Image 1.5.

**Ссылка на документацию API:** https://apidoc.cometapi.com/image-edits

## ЭТАП 1: ИЗУЧЕНИЕ ДОКУМЕНТАЦИИ И ПОДГОТОВКА

### Шаг 1.1: Изучение документации CometAPI

**Действия:**
1. Открыть https://apidoc.cometapi.com/image-edits
2. Найти раздел с моделями генерации изображений
3. Найти точные названия моделей:
   - GPT Image -1 (возможные варианты: `gpt-image-1`, `gpt-image-v1`, `openai-image-1`)
   - GPT Image 1.5 (возможные варианты: `gpt-image-1.5`, `gpt-image-v1.5`, `openai-image-1.5`)

**Что записать:**
- Точное название модели GPT Image -1: `gpt-image-1` (предположительно, требует уточнения в документации)
- Точное название модели GPT Image 1.5: `gpt-image-1.5` (предположительно, требует уточнения в документации)
- Endpoint для генерации: `/v1beta/models/{model}:generateContent` (тот же, что и для Gemini моделей)
- Формат запроса (JSON структура): `{"contents": [{"role": "user", "parts": [...]}], "generationConfig": {"responseModalities": ["TEXT", "IMAGE"]}}`
- Особые параметры (если есть): Не обнаружено, вероятно используется тот же формат

- `gpt_integration/photo_processing/image_client.py` - клиент для работы с API
- `gpt_integration/photo_processing/generator.py` - генератор примерки

**Проверить:**
